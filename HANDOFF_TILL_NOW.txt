# 5. First Important Discovery — Aider Edit Formats

Initial failures included:

```text
"The LLM did not conform to the edit format"
```

This became one of the most important lessons.

---

## Root Cause

Small local 7B models struggle with:

* diff format
* SEARCH/REPLACE format
* precise patch protocols

---

## Successful Fix

Use:

```bash
--edit-format whole
```

instead of:

```bash
--edit-format diff
```

---

## Final Stable Local Command

```bash
aider --model ollama/qwen2.5-coder:7b-instruct-q4_K_M \
      --edit-format whole
```
