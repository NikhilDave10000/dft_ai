COMMAND: foreach_in_collection

TITLE:
foreach_in_collection

DESCRIPTION:
This command is used to iterate each element in a collection.

SYNTAX:
string foreach_in_collection itr_var collections body

OPTIONS:
itr_var : Specifies the name of the iterator variable.
collections : Specifies a list of collections to iterate.
body : Specifies a script to execute per iteration.

EXAMPLES:
TEST-T> foreach_in_collection pin [filter_collection [get_pins] pin_pathname=~*slow_clk* ] {
? echo [get_attribute $pin pin_pathname]
? }
