COMMAND: filter_collection

TITLE:
filter_collection

DESCRIPTION:
This command filters a collection after the collection is created.

SYNTAX:
collection filter_collection [-regexp] [-nocase] collection1 expression

OPTIONS:
-regexp : Indicates that TestMAX ATPG regular expressions are used by the following filter
              operators: =~ and !~ . By default, these filter
              operators use simple wildcard pattern matching with the ’ * ’ and
                ’ ? ’ wildcards.
-nocase : Makes the pattern match case-insensitive.

EXAMPLES:
TEST-T> foreach_in_collection pin [filter_collection [get_pins] pin_pathname=~*slow_clk* ] {
? echo [get_attribute $pin pin_pathname]
? }
