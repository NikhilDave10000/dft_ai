COMMAND: extract_neighbors

TITLE:
extract_neighbors

DESCRIPTION:
Extracts the net pair data for all nets in the design.

SYNTAX:
extract_nets [-all] [-keep_physical | -nokeep_physical] [-names { driver_pins }] [-verbose]

OPTIONS:
-all : Extracts the net pair data for all nets in the design.
-keep_physical | -nokeep_physical : The -keep_physical option (the default) extracts and saves the neighboring
              nets and bridgeable areas for each specified net. The -nokeep_physical option excludes this information during extraction.
-names { driver_pins } : Extracts neighboring nets and bridgeable areas for nets based on the specified name(s) of a
              driver pin or pins. You can print the extracted information using the report_physical –net command.
-verbose : Prints a verbose report of the neighbor extraction.
