COMMAND: list_attributes

TITLE:
list_attributes

DESCRIPTION:
This command displays an alphabetically sorted list of currently defined attributes.

SYNTAX:
list list_attributes [-application] [-class class_name] [-nosplit]

OPTIONS:
-application : Lists the application attributes.
-class class_name : Lists only attributes of the class_name , which can be any of the
            following: Clock, ScanChains, Cell, Primitive, Pin, Port, Modules, Instances, Timings,
            Settings, Faults, Patterns, Candidates, DiagFile.
-nosplit : Prevents split lines when columns overflow.

EXAMPLES:
TEST-T> list_attributes -class clock
