COMMAND: report_serializers

TITLE:
report_serializers

DESCRIPTION:
This command generates a report containing data for the specified serializers.

SYNTAX:
report_serializers <<serializer_name> | -load | -unload |-all> -chain_segments [-verbose]

OPTIONS:
<serializer_name> : The name of the serializer for which you want to generate a report.
-load : Reports all load serializers.
-unload : Reports all unload serializers.
-all : Reports all serializers.
-chain_segments : Reports the scanin port and length for each load serializer segment and the scanout
            port and length for each unload serializer segment.
-verbose : Reports the data for the specified serializers in verbose mode.

EXAMPLES:
