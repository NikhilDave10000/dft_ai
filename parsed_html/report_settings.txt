COMMAND: report_settings

TITLE:
report_settings

DESCRIPTION:
This command reports the current settings defined by the set commands, such as the set_contention , set_atpg , and set_build commands. For a complete list of the
        set commands in TestMAX ATPG, see Set Commands .

SYNTAX:
report_settings -help Usage: report_settings # REPort SEttings [-all] () [-command_report] () < command_type | atpg | bist | build | buses | contention | delay | diagnosis | drc | distributed | faults | iddq | learning | messages | netlist | patterns | physical_db | pindata | primitive_report | random_patterns | sdc | simulation | vsv | wgl | workspace_sizes >

OPTIONS:
-all : Reports all command type settings for current session
-command_report : Formats the report to match the applied commands for the session so that they can be
              applied as part of a command file
-command_type : You can use any of the command type options that are mentioned and the details to
              see. If you do report_setting you can see all commands listed.
