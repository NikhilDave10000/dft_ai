COMMAND: report_sdc_analysis

TITLE:
report_sdc_analysis

DESCRIPTION:
Reports on gates are marked during exception tracing. To report on static SDC
              analysis before running ATPG or simulation, the set_sdc
                -mark_gui_gates command option must be set before running DRC.

SYNTAX:
report_sdc_analysis [-all] [-summary] [-verbose] [-static] [-dynamic] [-endpoint] [-data_exception_matrix] [-to_gate] [exception]

OPTIONS:
-static : Reports on gates are marked during exception tracing. To report on static SDC
              analysis before running ATPG or simulation, the set_sdc
                -mark_gui_gates command option must be set before running DRC. -all When used with the -static option; it reports the exception
                    ID, SDC file line number, and the number of affected gates for each exception.
                    There is also a percentage of gates in the design marked by this exception.
                    Since multiple exceptions can sometimes be created from the same line in an SDC
                    file, multiple exceptions can share the same line number. exception When used with the -static option; it reports the exception
                    type, the number of from gates, number of through gates, number of to gates, and
                    number of affected gates as well as the line number of the exception in the SDC
                    file. The percentage after the number of affected gates is the percent of all
                    gates in the design that were marked by the exception. -summary When used with the -static option; it reports a summary of
                    static exception tracing. Breaking up the report into number of
                    clock_exceptions, data_exceptions, total_exceptions, from_points,
                    through_points, to_points, startpoints, endpoints and affected_gates. It also
                    reports a number of optimized clock and data exceptions. Endpoints here are
                    DLAT/DFF/MEM/PIO/PO/TIEX. -verbose When used with the -static option; this adds the exception to
                    the report for an individual exception and adds the type, the number of from
                    gates, the number of through gates, and number of to gates for the -all option. -to_gate Reports the exception number that impacts the gate_id. Adding -verbose prints the full exception associated with the
                    exception number. -data_exception_matrix This option reports the different combinations of number of from and to gates
                    as well as how many exceptions there are of each type.
-all : When used with the -static option; it reports the exception
                    ID, SDC file line number, and the number of affected gates for each exception.
                    There is also a percentage of gates in the design marked by this exception.
                    Since multiple exceptions can sometimes be created from the same line in an SDC
                    file, multiple exceptions can share the same line number.
exception : When used with the -static option; it reports the exception
                    type, the number of from gates, number of through gates, number of to gates, and
                    number of affected gates as well as the line number of the exception in the SDC
                    file. The percentage after the number of affected gates is the percent of all
                    gates in the design that were marked by the exception.
-summary : When used with the -static option; it reports a summary of
                    static exception tracing. Breaking up the report into number of
                    clock_exceptions, data_exceptions, total_exceptions, from_points,
                    through_points, to_points, startpoints, endpoints and affected_gates. It also
                    reports a number of optimized clock and data exceptions. Endpoints here are
                    DLAT/DFF/MEM/PIO/PO/TIEX.
-verbose : When used with the -static option; this adds the exception to
                    the report for an individual exception and adds the type, the number of from
                    gates, the number of through gates, and number of to gates for the -all option.
-to_gate : Reports the exception number that impacts the gate_id. Adding -verbose prints the full exception associated with the
                    exception number.
-data_exception_matrix : This option reports the different combinations of number of from and to gates
                    as well as how many exceptions there are of each type.
-dynamic : Reports dynamically after the usage of the run_atpg command on the
              number of X’s created at endpoints by each exception. If two or more exceptions share
              an endpoint the X is considered shared and if the exception is the only exception with
              an endpoint, an X on the endpoint is considered confirmed. -all When used with -dynamic option; reports on all exceptions in order of combined
                    confirmed and shared Xs. exception When used with the -dynamic option; this reports on the
                    exception with the ID specified and the reported fields are the confirmed and
                    shared X’s propagated to the exception’s endpoints during timing exception
                    simulation. Confirmed X’s are on endpoints that are unique to the exception
                    while shared X’s are on endpoints that are common between more than one
                    exception, -summary When used with -dynamic option; reports a logarithmic summary
                    of the number of X’s produced by each exception. The number of X’s is the
                    combination of confirmed and shared X’s for each exception. -verbose When used with -dynamic option; prints the full exception
                    along with the ID, confirmed X’s, and shared X’s.
-all : When used with -dynamic option; reports on all exceptions in order of combined
                    confirmed and shared Xs.
exception : When used with the -dynamic option; this reports on the
                    exception with the ID specified and the reported fields are the confirmed and
                    shared X’s propagated to the exception’s endpoints during timing exception
                    simulation. Confirmed X’s are on endpoints that are unique to the exception
                    while shared X’s are on endpoints that are common between more than one
                    exception,
-summary : When used with -dynamic option; reports a logarithmic summary
                    of the number of X’s produced by each exception. The number of X’s is the
                    combination of confirmed and shared X’s for each exception.
-verbose : When used with -dynamic option; prints the full exception
                    along with the ID, confirmed X’s, and shared X’s.
-endpoint : Reports on the number of X’s added during simulation for endpoints. Threaded
              simulation is required for this report. The number of X’s added is for all patterns
              simulated with timing exception simulation. For ATPG, basic scan patterns do not run
              timing exception simulation and patterns that are discarded by ATPG are included in
              the number of X’s and pattern count. -all When used with the -endpoints option; reports on all exception
                    endpoints in order of number of Xs. Endpoint ID Reports on the endpoint with the ID specified. The endpoint ID is the gate ID
                    of the timing exception endpoint. The values reported are the number of Xs at
                    the endpoint during timing exception simulation and the percentage of patterns
                    where the endpoint was masked as X. -summary When used with -endpoints option; Gives a logarithmic scale
                    summary of the number of endpoints and how many X’s are propagated to them
                    during timing exception simulation. -verbose When used with the -endpoint option; it reports the exceptions
                    IDs for all exceptions that include the endpoint. The option set_simulation -map_exception_endpoints must be set before
                    running simulation using run_sim or else the error is reported
                    and N/A is printed for exception IDs. Error: " set_simulation -map_exception_endpoints " when not
                    set, cannot map X's from endpoints to exceptions.
-all : When used with the -endpoints option; reports on all exception
                    endpoints in order of number of Xs.
Endpoint ID : Reports on the endpoint with the ID specified. The endpoint ID is the gate ID
                    of the timing exception endpoint. The values reported are the number of Xs at
                    the endpoint during timing exception simulation and the percentage of patterns
                    where the endpoint was masked as X.
-summary : When used with -endpoints option; Gives a logarithmic scale
                    summary of the number of endpoints and how many X’s are propagated to them
                    during timing exception simulation.
-verbose : When used with the -endpoint option; it reports the exceptions
                    IDs for all exceptions that include the endpoint. The option set_simulation -map_exception_endpoints must be set before
                    running simulation using run_sim or else the error is reported
                    and N/A is printed for exception IDs. Error: " set_simulation -map_exception_endpoints " when not
                    set, cannot map X's from endpoints to exceptions.

EXAMPLES:
Example Script:

read_netlist lib.v -lib
read_netlist test.v
run_build top
set_delay -launch_cycle system_clock
set_drc test.spf
set_fault -model transition
set_sdc -mark_gui_gates -verbose
read_sdc <file_name>
set_delay -nopi_changes
set_delay -nopo_measures
add_po_mask -all
set_delay -common_launch_capture_clock
set_delay -allow_multiple_common_clocks
add_pi_constraints 0 scan_en
run_drc
report_sdc_analysis -static -summary
report_sdc_analysis -static -all -verbose
report_sdc_analysis -static 0 -verbose
report_sdc_analysis -data_exception_matrix
set_simulation -map_exception_endpoints
add_faults -all
set_atpg ..
run_atpg

report_sdc_analysis -endpoint -summary
report_sdc_analysis -dynamic -summary
report_sdc_analysis -endpoint -all -verbose > endpoint.rpt
report_sdc_analysis -dynamic -all -verbose  > dynamic.rpt
