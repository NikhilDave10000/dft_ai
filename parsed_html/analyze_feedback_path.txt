COMMAND: analyze_feedback_path

TITLE:
analyze_feedback_path

DESCRIPTION:
Use this command for determining whether a selected feedback network has a sensitizable feedback path.

SYNTAX:
analyze_feedback_path loop_id [-verbose]

OPTIONS:
loop_id : Specifies the loop ID number of the feedback path network to analyze. The loop ID is
            assigned during model building and can be displayed with the report_feedback_paths command.
-verbose : Displays verbose information.

EXAMPLES:
TEST> report_feedback_path -all

   1  10     1       pass
   2  10     1       pass
